# Dataset Licences and Consent Provenance
# ml/data/LICENSES.md
#
# CI GATE: ci/check_nfr.py verifies that every dataset path referenced in
# ml/data/*.py has a corresponding entry in this file. A PR that adds a new
# loader without an entry here will fail the build.
#
# Format per entry:
#   ## <dataset_id>          <- must match the id used in the loader
#   - Licence: <SPDX or plain text>
#   - Source URL: <canonical URL>
#   - Consent: <how consent was obtained>
#   - Restrictions: <any use restrictions>
#   - Provenance note: <anything else reviewers need to know>

## wlasl
- Licence: Research-only (see https://github.com/dxli94/WLASL/blob/master/LICENSE)
- Source URL: https://github.com/dxli94/WLASL
- Consent: Collected from publicly available ASL instructional videos; signers
  are public figures or consented contributors per the original dataset paper
  (Li et al., 2020, WACV).
- Restrictions: Non-commercial research use only. Do not redistribute raw
  videos. Landmark tensors derived from videos may be shared for reproducibility
  under the same licence.
- Provenance note: 2,000 ASL word classes, ~21,000 video instances. Signer
  identities are tracked in the metadata JSON; use signer_id for train/val/test
  disjoint splits (ADR-003).

## msasl
- Licence: Microsoft Research Licence Agreement (non-commercial)
- Source URL: https://www.microsoft.com/en-us/research/project/ms-asl/
- Consent: Collected from publicly available ASL instructional videos; see
  Joze & Koller (2019) for provenance details.
- Restrictions: Non-commercial research use only. Do not redistribute raw
  videos.
- Provenance note: 1,000 ASL word classes, ~25,000 video instances. Overlaps
  with WLASL on ~500 classes; cross-dataset eval is valid and encouraged.

## chicagofs
- Licence: CC BY 4.0 (ChicagoFSWild+)
- Source URL: https://home.ttic.edu/~klivescu/ChicagoFSWild.htm
- Consent: Collected from ASL fingerspelling videos on YouTube; signers
  consented to public posting. CC BY 4.0 allows research and commercial use
  with attribution.
- Restrictions: Attribution required. Cite Shi et al. (2018, 2019).
- Provenance note: ~7,000 fingerspelling sequences, 26 letters. Signer IDs
  available for disjoint splits.

## asl_citizen
- Licence: CC BY 4.0
- Source URL: https://www.microsoft.com/en-us/research/project/asl-citizen/
- Consent: Participants recruited and consented; see Desai et al. (2024).
- Restrictions: Attribution required.
- Provenance note: 2,731 ASL signs, 52 signers. Excellent demographic
  diversity (skin tone, age, handedness). Preferred source for fairness slices.

## in_house
- Licence: Proprietary — internal recordings
- Source URL: N/A (internal manifest at ml/data/in_house_manifest.json)
- Consent: All signers signed a consent form granting use for model training,
  evaluation, and publication of aggregate statistics. Individual clips are
  not redistributed. Consent forms stored in internal HR system.
- Restrictions: Internal use only. Do not commit raw video to this repo.
- Provenance note: Placeholder loader. Populate ml/data/in_house_manifest.json
  with {video_path, signer_id, label, split} entries before use.

## synth
- Licence: MIT (generated by this codebase)
- Source URL: ml/synth_landmarks.py, ml/synth_sequences.py
- Consent: N/A (synthetic)
- Restrictions: None
- Provenance note: Demoted to test fixture in v2. Used only for parity tests
  and fast iteration. Not used as training data.
